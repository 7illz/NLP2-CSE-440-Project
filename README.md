Multi-Class Text Classification System | Academic Project (CSE440)
Technologies: Python, TensorFlow (Keras), Scikit-Learn, Gensim, NLTK
Engineered an end-to-end NLP pipeline to automatically
categorize conversational Q&A data into 10 distinct domain
classes.
Developed and benchmarked deep learning models (LSTM, Bi
GRU, RNN, DNN) against classical ML algorithms to establish
performance guidelines for text classification.
Optimized semantic feature extraction by engineering text
preprocessing workflows (NLTK) and comparing TF-IDF against
dense word embeddings (Word2Vec/Gensim).
